## 회귀 테스트로 고정된 실제 결함

`test_control_characters_do_not_break_parsing` — `pdftotext -bbox` 는 수식 글리프를
XML 1.0이 금지하는 제어문자(`\x04` 등)로 내보낸다. 걸러내지 않으면 `ET.fromstring` 이
문서 전체를 거부해 `/api/page/*/words` 가 죽는다. 통합 검증에서 발견되어 고쳤고,
픽스처에 실제 제어문자를 넣어 재발을 막았다.
