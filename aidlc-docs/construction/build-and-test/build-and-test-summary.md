## 이 단계에서 발견한 결함

### 제어문자로 인한 XML 파싱 실패 (수정 완료)

`/api/page/252/words` 가 `ParseError: not well-formed (invalid token)` 로 죽었다.
`pdftotext -bbox` 는 수식 글리프를 **XML 1.0이 금지하는 제어문자**(`\x04` 등)로 내보낸다.
설계 문서에는 "빈 `<word></word>` 로 나온다"고 적었는데 — 터미널에서 안 보였을 뿐,
실제로는 내용이 있었다. `ET.fromstring` 이 문서 전체를 거부했다.

**왜 단위 테스트가 못 잡았나**: 픽스처를 사람이 손으로 쓴 깔끔한 XML로 만들어서
실제 출력의 지저분함을 재현하지 못했다. 이런 종류의 결함은 실물을 통과시켜야만 드러난다.

**수정**: 파싱 전에 금지 문자를 제거. 픽스처에 실제 제어문자를 넣어 회귀 테스트로 고정.

### (앞 단계에서 발견) `ask.sh` cwd 누락, `--session-id` 재사용 불가

Code Generation 단계에서 발견·수정. `code-summary.md` 참조.
