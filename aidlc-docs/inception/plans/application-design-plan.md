### 이 결과로 확정된 것

- [x] **QG-1 통과** — 워커는 `--allowedTools "Bash Read WebSearch" --permission-mode dontAsk` 조합이 필수.
      이 플래그가 빠지면 아무 도구도 못 쓴다
- [x] **OTD-1 해결 → `pdftoppm` PNG + `pdftotext -bbox` 투명 텍스트 레이어**

  원래는 "pdftoppm(의존성 0, 드래그 불가)" vs "pdf.js(드래그 가능, 1MB 벤더링)" 양자택일로 봤는데,
  실험 F가 **제3의 길**을 열었습니다. PNG 위에 단어 bbox 좌표로 투명 텍스트를 얹으면
  pdf.js와 같은 방식의 페이지 위 드래그 선택이 **외부 의존성 0**으로 가능합니다.
  두 원안보다 엄밀히 우월하므로 이것으로 확정합니다.

  *알려진 한계*: 수식 글리프는 빈 `<word></word>`로 나와 텍스트 레이어에 구멍이 생깁니다.
  즉 **수식 자체는 드래그로 잡히지 않습니다.** 다만 페이지 번호가 항상 함께 전송되므로
  워커가 실험 C 방식으로 원본 페이지 이미지를 직접 읽어 해결합니다

- [x] **OTD-2 소멸** — OTD-3(a) 헤드리스 확정으로 파일 감시 자체가 불필요해짐
- [x] **QG-3 / QG-4 사전 검증** — 렌더된 p.286의 헤더가 `252`로 오프셋 +34 재확인, 수식 전부 선명

```
qc_book/                          <- AI-DLC 프로젝트 트리

    server.py                     <- C2 미니 서버
```

- **C1 뷰어** — 페이지 이미지 + 투명 텍스트 레이어, 선택 캡처, 질문 전송, 답변 표시

- **C4 파일 계약** — 질문/답변/히스토리/상태

### Question 1: 답변 속 수식을 어떻게 표시할까요? ⭐ 중요

실험 C에서 워커가 수식을 **LaTeX로** 반환하는 것을 확인했습니다 (`\cos\frac{\theta}{2}=\sqrt{\frac{N-M}{N}}`).
문제는 브라우저가 LaTeX를 스스로 렌더링하지 못한다는 점입니다.

여기서 **NFR-2(외부 의존성 0)와 FR-5(수식을 읽을 수 있게 렌더링)가 정면으로 충돌합니다.**
지금까지는 poppler 하나로 의존성 0을 지켰는데, 수식 렌더링만은 공짜가 아닙니다.

**A) KaTeX를 한 번 내려받아 로컬에 벤더링** (약 300KB)

- 수식이 교재처럼 제대로 조판되어 보입니다. 렌더링 속도도 빠릅니다
- 대신 프로젝트 최초의 외부 JS 의존성이 생깁니다 (1회 다운로드 후 오프라인 동작)

**B) LaTeX 원문을 코드 블록으로 그대로 표시**

- 의존성 0 유지. `cos(θ/2) = sqrt((N-M)/N)` 같은 형태로 보입니다
- 복잡한 수식은 눈으로 따라가기 힘듭니다. 양자역학 교재에서는 꽤 불편할 수 있습니다

**C) 워커에게 "수식은 LaTeX 대신 유니코드로 써라"고 지시**

- `cos(θ/2) = √((N−M)/N)` 정도는 유니코드로 꽤 읽을 만합니다. 의존성 0
- 분수·행렬·큰 합 기호처럼 2차원 구조를 가진 수식은 표현이 무너집니다

**D) 하이브리드 — 간단한 수식은 유니코드(C), 복잡하면 워커가 "책 p.NNN 그림을 보라"고 안내**

- 의존성 0을 지키면서 복잡한 수식은 원본 페이지로 넘깁니다
- 어차피 좌측에 그 페이지가 떠 있으므로 자연스러울 수 있습니다

**X) Other** (직접 설명)

[Answer]: A. 수식을 읽는데 불편함이 없어야 해

### Question 2: 이전 질문의 맥락을 이어갈까요?

`claude -p` 는 기본적으로 매 호출이 독립입니다. `--session-id` 를 고정하면 대화가 이어집니다.

**A) 이어감 — 세션 ID 고정**

"방금 그거 더 설명해줘", "아까 말한 거랑 어떻게 달라?" 가 통합니다.
대신 대화가 길어질수록 매 호출의 입력 토큰이 누적되어 점점 느려지고, 주기적 초기화가 필요합니다.

**B) 매 질문 독립**

항상 일정한 속도. 대신 후속 질문을 할 때마다 맥락을 다시 적어야 합니다.
(페이지 번호와 선택 문장은 어차피 자동 첨부되므로 완전히 맥락이 없진 않습니다)

**C) 절충 — 최근 N개 Q&A만 프롬프트에 요약해서 넣음**

맥락을 어느 정도 유지하면서 토큰 누적을 제한합니다. 구현이 조금 늘어납니다.

**X) Other**

### Question 3: 서버를 어떻게 띄울까요?

**A) 터미널에서 수동 실행** — `python server.py` 하고 브라우저 열기. 가장 단순하고 상태가 눈에 보임

**C) launchd 자동 시작** — 맥 부팅 시 항상 떠 있음. 설정 파일이 하나 늘고 디버깅이 번거로워짐

### Question 6: 실험 F의 한계를 확인해 주세요

구현이 늘어나지만, 수식 블록을 정확히 지목할 수 있습니다.
